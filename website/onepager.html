Overview

Overzicht

Rails engine gem that watches Sidekiq, Delayed Job, Solid Queue, and custom job tables for anomalies — then notifies via webhook and shows an ops dashboard.

Rails engine gem die Sidekiq, Delayed Job, Solid Queue en eigen job-tabellen bewaakt op anomalieën — waarschuwt via webhook en toont een ops-dashboard.

Mode: thread / cron Modus: thread / cron Status: open source Status: open source Ruby ≥ 3.0 Rails ≥ 6.1 MIT

Quick install

Snel installeren

Add the gem, run the installer, mount the engine, open /anomonitor.

Voeg de gem toe, draai de installer, mount de engine, open /anomonitor.

# Gemfile
gem "anomonitor", github: "flori-s/anomonitor"

# config/routes.rb
mount Anomonitor::Engine => "/anomonitor"
